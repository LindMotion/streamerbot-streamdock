# Uninstall

Double-click **`uninstall.bat`**.

That closes FIFINE Control Deck, deletes only this plugin folder, and starts the app again:

`%APPDATA%\HotSpot\StreamDock\plugins\LindMotion SB Plugin.sdPlugin`

Do not delete other `.sdPlugin` folders.

You can also uninstall by hand:

1. Quit **fifine Control Deck**.
2. Delete the folder above.
3. Start FIFINE Control Deck again.
